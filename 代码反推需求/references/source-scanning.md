# 采集线索

读代码的取向：从对外行为往下读，读到业务判断、数据落点、外部交互为止。既要业务语义，也要技术事实。

## 分层投入

| 层次 | 内容 | 投入 | 提取什么 |
|---|---|---|---|
| 对外入口 | 用户可触发的功能 | 细读 | 功能边界、接口契约、输入项、校验、结果 |
| 业务处理 | 判断、状态变更、计算、规则 | 细读 | 决策表、状态迁移、公式、规则编号 |
| 数据访问 | 读写的数据与条件 | 细读 | 表与字段、查询过滤、唯一约束、事务边界 |
| 异步与中间件 | 缓存、消息、定时、锁 | 细读 | 触发时机、消息内容、幂等、失败处理 |
| 外部集成 | 第三方与跨系统调用 | 中读 | 契约、返回码、超时、失败表现、补偿 |
| 配置 | 可调项与开关 | 中读 | 配置项、默认值、影响分支、环境差异 |
| 组装与转换 | 数据格式转换、字段映射 | 略读 | 仅记录影响展示或存储的差异（精度、截断） |
| 框架能力 | 框架自带 | 跳过 | 不记录 |

## 按线索检索

### 功能与接口
- 找对外可触发的入口，**按业务功能归类，不按代码位置归类**
- 同一业务的多个入口合并描述（PC 与移动端只写一次，差异单列）
- 每个接口记录：路径、方法、鉴权、幂等、限流、超时、请求字段、响应字段、错误码
- 内部使用的入口（后台任务、内部工具）单列，标"非用户直接触发"
- 注意网关层：路由前缀、统一鉴权、请求头注入，这些会改变实际契约

### 判断与规则
- 条件分支：逐个确认业务含义，而非代码含义
- 校验分层：参数格式与必填、业务资格与限额、当前状态能否操作、是否重复
- 默认分支与"其他值"
- 唯一约束：导致哪个重复操作失败、用户看到什么
- 查询过滤：默认带上的条件（排除已删除、限本人数据、限状态）会导致"查不到"，必须写
- 外部返回码：对方各类结果分别怎么处理

### 状态
- 收集全部状态值，含未使用但已定义的
- 找全部变更点：用户操作、定时任务、回调、批量、人工修正
- 状态变更的前置校验
- 依赖状态但不改状态的功能：列表、统计、导出

### 数据
- 每张表：用途、字段业务含义、类型长度、必填、默认值、枚举
- 主键、唯一约束、索引（及对应查询场景）
- 关联关系与外键方式
- 分表与分片规则
- 事务边界：哪些写操作同一事务、失败回滚范围
- 标记删除：删除后哪些查询仍可见
- SQL 内的业务逻辑：视图、触发器、存储过程、CASE WHEN、批量更新语义

### 异步与中间件
- **写库后的读取端必须找到**（表驱动异步：谁在扫这些数据、多久一次、什么条件）
- 缓存的键规范、过期、失效时机、不一致窗口
- 消息的生产点、topic、消息体业务字段、消费幂等、重试与死信
- 定时任务的名称、频率、扫描条件、单次处理量、重复执行是否有害
- 延迟触发与补偿、对账任务
- 分布式锁的场景、粒度、超时、失效后果

### 时间
- 超时、有效期、结算周期、生效时间
- 定时任务执行频率与业务动作
- 日期比较边界（含不含端点）
- 节假日与工作日处理
- 存储精度与展示精度差异

### 数值
- 金额、数量、比例、积分的全部计算
- 每步舍入位置与方式
- 展示值与存储值精度差异
- 除零、负数、空值、溢出

### 配置
- 可调项、默认值、取值范围
- 开关型配置控制的分支
- 环境差异
- 代码中写死、本应可配置的数值（写当前固定值并标待确认）

### 外部依赖
- 依赖对象、调用时机、出入参业务含义
- 超时设置、失败与异常分别表现
- 重试、降级、兜底
- 回调验签、返回码映射
- 数据不一致的补正方式

### 用户可见文案
- 原文摘录提示、报错、确认框、成功告知
- 区分拦截性错误与告知性提示
- 占位符位置（金额、数量、名称）

### 隐含行为（最容易漏）
逐项检查：
1. 状态过滤导致"数据像丢了"
2. 唯一约束导致重复提交失败
3. 标记删除后仍出现在某些查询
4. 分页与默认排序规则
5. 批量操作的部分成功与全失败
6. 并发操作结果（重复点击、两人同时改同一单）
7. 权限范围导致"看不到别人创建的数据"
8. 跨日/跨月的统计归属
9. 数值展示的截断与补零
10. 空数据时的默认展示

## 记录方式

按业务对象与功能分组归档，不按文件分组。每条记录含：业务含义、触发条件、结果、用户可见表现、涉及的数据与中间件、置信度。疑点直接进待确认清单，不要停下来猜。
